# Proposal

## Why

2026-10-14 的第5课课件明确要求教师管理多个本班智能体，各自绑定提示词、技能和材料；学生选定智能体建立会话，再按绑定路由技能和检索。当前实现只有班级提示词和单一技能开关，不能覆盖新版验收。本次在现有个人仓增量修正，不重建项目、不删除业务数据。

## What Changes

- 增加本班多智能体管理、技能文本文件解析与 CRUD、两份绑定；学生可列出可用智能体和本班技能。
- 会话创建必须选择本班已启用智能体，之后不可更换；教师亦可创建和读取自己的会话。停用只阻止新会话，既有会话继续使用该智能体。
- 每轮读取智能体最新配置及绑定，词法计分至多选一个已绑定已启用技能，只在已绑定本班材料内混合检索；技能资料字段再过滤标题。
- 系统消息承载角色、技能与边界；编号资料位于用户消息。空提示词使用默认角色，零命中继续生成且不输出编号或伪造出处。
- SSE 改为 meta、delta、done、error，引用和技能在 meta 先发；问题2–500字，历史末尾6条、各500字，证据各800字。
- 从处理器注解生成 OpenAPI，保留本地 Swagger；更新 URL 组织的接口脚本、数据库断言和 HTML 报告。
- 增量迁移旧配置为一个默认智能体，并把旧会话关联到它；保留旧配置接口供兼容，但新回答链路不读取班级配置表。

## Capabilities

### New Capabilities

- `assistant-prompt-management`: 本班智能体、角色提示词和材料/技能绑定的管理与迁移。
- `guided-problem-solving`: 技能文件解析、候选集内词法路由、限定绑定材料检索和解题引导。
- `streaming-conversations`: 固定智能体的私有会话、meta SSE、消息历史和生成故障恢复。

### Modified Capabilities

无。本变更在第四课检索实现上增加材料范围，不改变既有检索/单次问答接口。

## Impact

新增 tutor_agents、skills 与关联表，给会话和消息增量增加智能体/技能留痕。前后端、OpenAPI 生成器、接口验收同步调整。密钥仍只存本机 .env；保留 Bearer 不透明会话令牌，课件预习页的 JWT 是方案参考，不要求更换现有认证。

## Non-goals

不引入 MCP、子代理、模型自主工具选择、作业批改或通用 SKILL.md 执行器。本课自定义技能文件只接受 knowledge_search。不开放跨班或他人会话，不让学生修改配置。
