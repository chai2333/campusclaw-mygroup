# Spec Delta

## ADDED Requirements

### Requirement: 本班技能文件解析与维护
教师 MUST 可上传或编写技能文件并新建、更新、删除本班技能；登录用户可列出/读取本班技能。文件最多8000字，以首个空行分割元数据与正文；名称、适用条件、启用必填，名称1–32字、适用条件1–120字、资料0–32字、正文1–2000字。未知/重复字段、无正文、非法启用值和非knowledge_search工具 MUST 返回可读400。名称班内唯一；跨班或未知对象同形404。

#### Scenario: 拒绝非法技能
- **WHEN** 输入重复名称字段、缺启用、非法工具或超过限制
- **THEN** 返回可读400且不写入部分数据

#### Scenario: 保留原文供编辑
- **WHEN** 教师保存合法中文字段技能文件
- **THEN** 解析结果与原文一并保存，读取可取回全文

### Requirement: 绑定候选集内确定性路由
系统 MUST 只对所选智能体绑定且启用的技能按适用条件词法计分，中英文逗号、顿号、分号、竖线切词并统一小写；每个命中词一分，最高分且最小编号胜出，零分不选，至多选一个。

#### Scenario: 同分与未绑定技能
- **WHEN** 两个绑定技能同分且未绑定技能更高分
- **THEN** 忽略未绑定者，选择绑定候选中编号较小者

### Requirement: 绑定材料内检索与学科过滤
检索 MUST 在登录班级且智能体绑定材料内执行，复用第四课混合排序取前4条，再剔除空正文和标题不含所选技能资料字段的结果，并连续编号。空绑定 MUST 直接返回空证据不调用检索。引用标题、切片位置和摘录 MUST 对应当轮证据。

#### Scenario: 同班未绑定材料更相关
- **WHEN** 同班存在更相关但未绑定的材料
- **THEN** 该材料不进入候选集或回答引用，不挤掉绑定材料命中

### Requirement: 角色技能与证据分离
系统消息 MUST 仅含智能体角色、选中技能和平台边界；编号材料 MUST 在用户消息并标识为不可信数据，每条最多800字。无命中 MUST 仍按角色与技能生成，引用为空且输出无[n]编号，不以固定未找到文案结束。技能名含解题引导时 MUST 指出下一步或错误位置，不直接给最终答案、选项、得数或整题过程。

#### Scenario: 无资料照常生成
- **WHEN** 检索落空或智能体空材料绑定
- **THEN** 调用对话网关、逐段生成，跨chunk剥除编号，数据库正文等于delta拼接且引用为空

#### Scenario: 停用引导后的回答变化
- **WHEN** 教师停用或解绑引导技能后在旧会话重放同一问题
- **THEN** 下一轮不注入引导技能，回答方式明显不同

#### Scenario: 资料注入不提升权限
- **WHEN** 材料包含忽略规则或泄露配置的指令
- **THEN** 资料仅为用户消息中的数据，回答和日志不泄露秘密、不越过班级与绑定边界
