# Spec Delta

## Purpose
为本班教师和学生在既有多智能体问答中接入自建MCP工具。通过服务器登记发现、最小候选集、模型决策与宿主复核，让真实工具调用可授权、可降级、可审计，同时保持凭据和班级数据的服务端边界。

## ADDED Requirements

### Requirement: 自建工具服务
系统 SHALL 在同仓mcp-server/提供Bearer保护的POST /mcp及公开/health，支持JSON-RPC 2.0 initialize、tools/list、tools/call，至少两个提示型工具，与主API同Compose网络启动。
#### Scenario: 协议与鉴权
- **WHEN** 分别无令牌、错误令牌和有效令牌请求发现/调用
- **THEN** 前两者401，有效者列出formula_hint/unit_convert并得到文本提示；非法请求返回可读JSON-RPC错误，不直接给最终数值答案。

### Requirement: 班级登记发现和令牌边界
系统 SHALL 仅允许教师管理本班服务器，名称本班唯一，支持修改/删除/连接/断开。连接必须握手和发现，成功整体替换缓存，失败或断开清空并置未连接。令牌加密存服务端，只返回token_configured布尔值；不得进入日志、模型、前端代码或镜像。
#### Scenario: 缓存和隔离
- **WHEN** 重复连接、改错令牌、断开或跨班按ID访问
- **THEN** 缓存不翻倍，失败/断开不可调用，跨班与不存在同404；学生管理接口403。

### Requirement: 技能候选集与保存校验
系统 SHALL 支持knowledge_search及小写工具名@服务器名引用（工具段无连字符），保存校验本班已连接、已发现且批准的工具。仅选中技能里的MCP工具可以成为模型候选。
#### Scenario: 错误绑定
- **WHEN** 保存大写/缺服务器/未发现/未连接/跨班引用
- **THEN** 可读400且技能不变，不泄露其他班级服务器存在性。

### Requirement: 模型决策与调用循环
系统 SHALL 把发现的名称、完整说明和同一输入Schema转成模型函数声明，由模型填参；宿主按Schema校验并逐调用复核当前连接/批准状态，再带专属令牌执行。结果作为带来源的tool角色数据消息回传。支持至少两轮，轮次、每轮/每次提问次数及会话累计次数受限，超限撤下工具并按已有信息生成回答；工具错误不阻断检索与生成。
#### Scenario: 连续调用与降级
- **WHEN** 模型连续请求两轮或超过配置上限、参数不合法、远端超时
- **THEN** 合法调用实际发往同仓服务；达到上限不再执行，错误如实回传，仍能完成回答。
#### Scenario: 配置后失效
- **WHEN** 绑定后断开/删除服务器，或模型尝试候选外工具
- **THEN** 调用结果明确denied；存在且可归属的本班服务器写拒绝审计，不存在/跨班不写入他班记录。

### Requirement: 信任边界和说明变更
系统 SHALL 在模型输入前检查工具文本，命中已知指令式注入整条替换固定说明，不将结果写系统消息。每工具单独批准，声明外发/写入的工具不得自动执行；重新发现说明或结构改变须记录并暂停批准，教师可查看完整变更后重新确认。
#### Scenario: 注入和变更
- **WHEN** 工具返回忽略规则/泄露凭据指令，或重新发现改变说明
- **THEN** 整条恶意结果丢弃并记error，模型得到固定失败说明；变更有记录且重新确认前不可执行。

### Requirement: 流式可观测性和审计
系统 SHALL 在正文首字前通过meta.tool_calls报告ref/status/text/round，按轮次增量报告；无调用省略字段。调用状态持久化，刷新可恢复；教师查看本班倒序审计，含工具、服务器、状态、用户、会话/消息、轮次、时间、摘要/原因，不含令牌。
#### Scenario: 成功拒绝错误记录
- **WHEN** 分别成功、断开拒绝、工具报错后查询审计和刷新会话
- **THEN** 状态ok/denied/error均可追溯且与流式/历史一致，其他班级不可见。

### Requirement: 文档与验收交付
系统 SHALL 通过注解生成OpenAPI并保留Swagger试调；apitest按URL每接口一脚本，一键生成不提交的HTML报告，包含响应与DB一致性、真实MCP链路与第3–5课回归。
#### Scenario: 可复核交付
- **WHEN** 执行独立测试并升级本机服务
- **THEN** 保留原业务数据与备份，记录真实模型和模拟测试的区别；课堂同伴本人验证只在实际完成后记为通过。
