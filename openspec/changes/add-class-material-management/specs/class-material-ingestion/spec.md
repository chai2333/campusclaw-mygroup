# Spec Delta

## Purpose

定义教研材料从教师上传、文本校验、原子入库到本班检索筛选、详情展示和鉴权下载的完整行为，并规定登录与材料页面的交互、视觉、安全和失败反馈以支持第 3 课的可复核交付。

## ADDED Requirements

### Requirement: 教师上传与严格文件校验
系统 SHALL 通过 POST /api/materials 接收教师的单个 multipart file，仅允许非空 UTF-8 .txt/.md，MUST 在有界读取中执行扩展名、内容与可配置大小校验。

#### Scenario: 合法文本
- **WHEN** 本班教师提交受支持文件
- **THEN** 同步解析入库完成后返回 201 与材料 ID，本班立即可查。

#### Scenario: 不支持格式或伪装
- **WHEN** 提交 .exe、.md.exe、二进制伪装或与内容不符 MIME
- **THEN** 返回 400，无材料、知识条目或文件残留。

#### Scenario: 非法内容
- **WHEN** 提交空白、空文件或非 UTF-8 内容
- **THEN** 返回 400，无残留，不回显正文。

#### Scenario: 文件超限
- **WHEN** 已知长度或流式内容超出配置上限
- **THEN** 返回 413，停止有界读取，不先接收完整超限内容，无残留。

#### Scenario: 缺失或多个文件
- **WHEN** 上传请求缺少 file 或包含重复 file
- **THEN** 返回 400，无写入。

#### Scenario: 学生上传
- **WHEN** 学生绕过界面直接提交合法文件
- **THEN** 返回 403，不保存、不解析、不入库，文件和两表计数不变。

### Requirement: 存储路径不受客户端文件名控制
系统 MUST 生成随机存储键，原文件名仅为展示元数据；原文件不可经公开静态路径读取。

#### Scenario: 路径穿越文件名
- **WHEN** 上传文件名包含 ../ 或绝对路径
- **THEN** 文件只能写入受控上传目录的随机键位置，不覆盖任意文件。

#### Scenario: 静态读取尝试
- **WHEN** 任意用户直接请求 /uploads/ 猜测路径
- **THEN** 不能获取原文件，无静态旁路；合法读取仅通过鉴权下载接口。

### Requirement: 上传与知识入库失败零残留
系统 MUST 同步完成文件与材料/知识条目入库；两表同事务，失败回滚并清理文件，不持久化本次 failed/processing 材料作为失败残留。

#### Scenario: 成功一致性
- **WHEN** 上传成功返回 201
- **THEN** 材料有 ID、标题、原文件名、上传者、班级、入库时间及 ready 状态，全部知识条目保存完整有序正文与材料关联，原文件可下载。

#### Scenario: 解析或数据库写入失败
- **WHEN** 解析失败或材料/知识条目写入任一步失败
- **THEN** 解析错误 400；数据库故障 503；两表不新增、已写文件被删除，不留半提交。

#### Scenario: 文件写入失败
- **WHEN** 临时文件写入或最终移动失败
- **THEN** 返回 500，两表回滚并清理本次文件，错误无内部路径。

#### Scenario: 崩溃恢复
- **WHEN** 上传期间进程中断后重启
- **THEN** 在就绪前清理无已提交记录关联的临时/孤儿文件，已提交有效材料和文件保持完整；对账或清理失败不就绪。

### Requirement: 本班列表与普通搜索
系统 SHALL 从数据库查询当前班级 ready 材料，展示标识、标题/原文件名、上传者与入库时间；搜索 SHALL 支持本班标题及正文普通文本匹配。

#### Scenario: 上传后可查
- **WHEN** 教师上传成功后同班教师或学生查询列表
- **THEN** 出现同 ID 的真实数据库材料，其他班级不可见。

#### Scenario: 标题或正文匹配
- **WHEN** 用户输入材料标题片段或正文片段搜索
- **THEN** 仅显示本班匹配结果，清空搜索恢复列表。

#### Scenario: 空状态
- **WHEN** 班级无材料或搜索无匹配
- **THEN** 分别展示无材料和无匹配提示，不填充硬编码演示项。

### Requirement: 详情与鉴权下载
系统 SHALL 提供 GET /api/materials/{id} 返回本班正文和元数据，GET /api/materials/{id}/file 下载原文件；教师与学生均可读取，授权语义遵循 class-data-isolation。

#### Scenario: 详情来源
- **WHEN** 用户打开本班材料详情
- **THEN** 看到标题、班级、上传者、入库时间及按知识条目重建的完整正文，无存储键、绝对路径。

#### Scenario: 下载原文
- **WHEN** 同班教师或学生下载材料
- **THEN** 200 attachment，内容与上传原文件一致，文件名安全编码，含 nosniff。

#### Scenario: 文件缺失
- **WHEN** 本班材料记录存在但原文件缺失
- **THEN** 下载返回 404 且不泄露路径，不返回其他文件。

### Requirement: 前端身份恢复与错误状态
系统 SHALL 提供登录页与材料页，使用 JSON 认证 API 并以 /api/me 返回身份渲染功能，MUST 不依赖浏览器持久化角色作为授权依据。

#### Scenario: 登录刷新退出
- **WHEN** 用户登录、刷新/重开材料页并退出
- **THEN** 登录为 JSON /api/login；恢复调用 /api/me；退出调用 /api/logout，回到登录状态。

#### Scenario: 角色入口
- **WHEN** 分别以教师和学生打开页面并修改 localStorage role
- **THEN** 只有真实教师显示上传入口及上传命令，本地伪造值不影响。

#### Scenario: 业务 401
- **WHEN** 任意业务请求返回 401
- **THEN** 清除内存身份和材料数据，回到登录页，不保留前一用户内容。

#### Scenario: 业务 403/404/503
- **WHEN** 接口分别返回拒绝、不存在或服务不可用
- **THEN** 展示对应可读反馈，不篡改响应语义；503 不误清认证或提示密码错误。

### Requirement: 品牌主题与响应式布局
系统 SHALL 使用北大红主色的原生 CSS 设计系统，提供浅色/深色与响应式布局、可访问名称及键盘焦点。

#### Scenario: 主题切换
- **WHEN** 用户首次访问后手动切换主题并刷新
- **THEN** 首次跟随系统，之后保持手动偏好；主要页面和详情/命令面板使用一致 token。

#### Scenario: 移动与键盘
- **WHEN** 在 320px 手机及桌面宽度用鼠标或键盘操作
- **THEN** 主要操作可达，无页面级横向溢出，表格可局部滚动，控件有名称且焦点可见。

### Requirement: 材料双视图
系统 SHALL 提供列表/网格切换，两者使用同一班级数据与搜索结果。

#### Scenario: 切换视图
- **WHEN** 用户搜索后切换列表/网格并刷新
- **THEN** 材料集合和搜索条件不因切换改变，视图偏好保存，详情/下载均可操作。

### Requirement: 命令面板
系统 SHALL 提供 Cmd/Ctrl+K 命令面板，支持本班材料搜索/打开及主题、视图操作，教师可打开上传。

#### Scenario: 键盘操作
- **WHEN** 使用快捷键打开后上下选择、Enter 执行、Escape 关闭
- **THEN** 选中命令执行，关闭后焦点恢复原控件。

#### Scenario: 权限和范围
- **WHEN** 学生或 A 班用户搜索命令与材料
- **THEN** 学生无上传命令，A 班不显示 B 班材料，注销清除缓存。

### Requirement: 上传进度与结果通知
系统 SHALL 展示真实上传字节进度、服务端入库阶段和可读成功/失败反馈，并防止重复提交。

#### Scenario: 上传到入库
- **WHEN** 教师上传文件至传输达到 100% 但尚未收到成功响应
- **THEN** 显示正在入库，不提前报成功；201 后 toast 成功并刷新本班列表。

#### Scenario: 失败与重试
- **WHEN** 网络断开或返回校验/服务器错误
- **THEN** 显示错误并恢复重试能力，不加入虚假列表项。

#### Scenario: 可访问反馈
- **WHEN** 出现成功或失败通知
- **THEN** 屏幕阅读器可接收状态提示，错误不只依赖颜色，进行中不能重复提交。

### Requirement: 正文安全与 GFM 展示
系统 SHALL 将 txt 当纯文本、md 按 GFM 格式展示；MUST 禁止材料中的脚本、原始 HTML 及危险 URL 执行。

#### Scenario: 正常 GFM
- **WHEN** 查看包含表格、代码、列表及任务列表的 md
- **THEN** 正确格式化且正文来自知识库。

#### Scenario: 恶意正文
- **WHEN** 查看包含 script、事件属性、HTML 或 javascript URL 的 txt/md
- **THEN** 不执行脚本、不注入可执行 HTML、不导航危险 URL；txt 字面转义展示。
