# Proposal

## Why

当前版本的本班材料搜索依赖逐篇加载正文后做子串匹配，无法按知识片段返回相关结果，也不能准确指出命中内容在什么材料、什么位置。第四课需要把检索边界和来源溯源变成可验收合同，使师生能安全地找到本班知识并核对原文。

## What Changes

- 新增面向已入库知识片段的检索能力；每次检索只可访问当前会话用户所属班级的材料。
- 检索结果按命中的知识片段返回，包含材料身份、原文件名、标题、分段位置和命中原文，以便用户追溯来源。
- 支持关键词检索，并为语义向量检索预留实现路径；具体存储选型由设计说明评估，向量索引不得成为绕过班级授权的依据。
- 增加无结果、无班级身份、跨班隔离、缺失来源和检索依赖不可用等行为约定。
- 保留已有材料列表、详情与下载合同；不以检索结果替代材料对象授权。

## Capabilities

### New Capabilities

- `class-scoped-knowledge-retrieval`: 对当前班级已入库知识片段进行检索，并为每个命中提供可核验的材料和片段来源。

### Modified Capabilities

无；当前主规格目录没有已归档能力规格。

## Impact

- API：新增本班知识检索端点或等价 API 行为；扩展结果 DTO 以携带材料与片段溯源信息。
- 后端：复用现有 `materials`、`knowledge_entries` 与服务端身份班级；增加检索与来源校验逻辑。
- 数据存储：MySQL 继续作为材料、正文片段、归属和来源元数据的权威存储；设计将评估是否增加向量数据库及其一致性策略。
- Web：提供检索输入、命中片段展示及打开来源材料的交互。
- 验收：覆盖本班命中、跨班不可见、伪造班级声明无效、来源准确及依赖故障路径。
