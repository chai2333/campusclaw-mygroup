# Spec Delta

## Purpose

使师生能够在当前班级已授权的知识材料中检索相关片段，并查看每条命中的原始材料和位置，以验证内容上下文和来源。

## ADDED Requirements

### Requirement: 检索范围由当前用户班级决定

系统 MUST 仅检索当前已认证用户所属班级中状态为 ready 的材料与知识片段。检索范围 MUST 从服务端当前身份解析，客户端提供的班级、角色或材料范围声明 MUST NOT 扩大检索范围。没有班级归属的用户 MUST 收到 `403`，未认证用户 MUST 按现有认证合同拒绝。

#### Scenario: 用户只能检索本班知识
- **WHEN** 已认证用户提交检索请求
- **THEN** 结果只包含该用户班级中 ready 材料的知识片段

#### Scenario: 伪造班级声明不能扩大范围
- **WHEN** 用户在查询参数、请求头或请求体中提供其他班级 ID
- **THEN** 系统忽略该声明，结果范围仍由当前用户数据库身份确定

#### Scenario: 用户没有班级归属
- **WHEN** 已认证用户没有关联班级并提交检索请求
- **THEN** 系统返回 `403` 且不返回任何知识片段或材料元数据

#### Scenario: 不同班级的相同查询互不泄露
- **WHEN** 两个班级各自存在与同一查询匹配的知识片段
- **THEN** 每个用户只收到其所属班级的命中，响应不暴露其他班级命中数量或来源

### Requirement: 检索返回可追溯的知识片段

系统 MUST 将命中结果以知识片段为单位返回，并为每个结果提供足以核验来源的信息，包括材料 ID、标题、原文件名、片段序号和命中原文片段。系统 MUST 提供打开受保护材料详情的引用标识或链接；来源对象不存在、未就绪或不属于当前班级时 MUST 不返回该命中。溯源信息 MUST NOT 暴露文件系统路径或内部存储键。

#### Scenario: 命中展示材料与片段来源
- **WHEN** 本班某知识片段匹配检索条件
- **THEN** 结果同时包含该片段内容、材料标题、原文件名、材料 ID 和片段序号

#### Scenario: 同一材料有多个命中片段
- **WHEN** 同一材料中的多个不同片段分别匹配查询
- **THEN** 每个片段作为独立命中返回，序号能够区分它们且内容顺序与来源正文一致

#### Scenario: 来源材料失效或越权
- **WHEN** 命中关联的材料已不存在、未就绪或不属于当前用户班级
- **THEN** 系统从结果中排除该命中，不泄漏该材料的元数据

#### Scenario: 返回来源引用
- **WHEN** 客户端展示检索命中
- **THEN** 它可使用结果中的引用标识打开现有受保护材料详情，并继续遵循详情接口的班级授权

### Requirement: 检索输入与命中结果有界

系统 MUST 验证并限制检索文本长度及单次返回的命中数量，结果 MUST 按明确且稳定的相关性顺序返回；相关性相同的结果 MUST 使用确定性的次序打破平局。空查询或规范化后无效的查询 MUST 返回客户端错误，不得退化为全库/全班列表。没有匹配时系统 MUST 返回成功的空结果集合。

#### Scenario: 空白查询被拒绝
- **WHEN** 用户提交空字符串或仅含空白的查询
- **THEN** 系统返回参数错误，且不执行全量材料检索

#### Scenario: 超出输入或结果上限
- **WHEN** 查询文本超过规定长度或请求的返回数量超过服务端允许上限
- **THEN** 系统返回明确参数错误或将数量限制在服务端上限内，且响应不会超过该上限

#### Scenario: 无匹配项
- **WHEN** 有效查询在用户本班没有匹配知识片段
- **THEN** 系统返回成功状态及空命中列表

#### Scenario: 同相关性结果稳定排序
- **WHEN** 多个结果的相关性相同且数据未变化
- **THEN** 重复请求按同一确定性次序返回这些结果

### Requirement: 关键词与语义检索遵循相同授权和溯源合同

系统 MUST 支持关键词检索。若部署启用语义向量检索，向量候选 MUST 在服务端按当前班级范围约束，并且返回前 MUST 重新验证权威材料归属与状态；向量命中和关键词命中 MUST 遵守相同的输入、结果限制、来源信息和错误语义。向量服务不可用时系统 MUST 不返回未经授权或无法溯源的候选，并 MUST 以明确的服务不可用响应处理，不得静默地把空结果伪装成正常无匹配。

#### Scenario: 关键词查询产生本班结果
- **WHEN** 用户以关键词查询已入库正文
- **THEN** 系统只返回本班匹配片段及其可追溯来源

#### Scenario: 语义检索启用时应用班级过滤
- **WHEN** 启用语义检索且向量服务返回相似候选
- **THEN** 系统仅返回经班级过滤并通过权威材料记录复核的本班候选

#### Scenario: 向量服务故障
- **WHEN** 已启用的向量检索依赖超时或不可用
- **THEN** 系统返回明确的 `503` 服务不可用响应且不伪报正常空结果

### Requirement: 检索响应保护用户数据

系统 MUST 对检索 API 执行认证、班级授权及与材料内容相同的敏感响应缓存控制。响应、错误和审计日志 MUST NOT 包含会话凭据、其他班级内容、绝对文件路径或向量数据库内部连接信息。

#### Scenario: 未认证请求检索
- **WHEN** 请求没有有效会话
- **THEN** 系统按现有 API 认证约定拒绝且不返回命中内容

#### Scenario: 检索结果不可被共享缓存
- **WHEN** 系统返回检索命中或用户特定的错误
- **THEN** 响应使用禁止共享缓存的策略

#### Scenario: 检索失败日志脱敏
- **WHEN** 检索数据库或向量依赖发生故障
- **THEN** 服务端可记录操作和故障类别，但不记录 Cookie、完整正文或机密连接信息
