## 上传合同待明确

普通的校验、解析、写入失败可以回滚数据库并删除文件。`COMMIT` 已发送后若连接中断，客户端可能不知道服务器是否已经提交。此时直接删除文件可能破坏已经提交的材料；返回错误并保留文件等待核对又不符合“任意失败请求立即零残留”的绝对表述。

建议补充“提交结果不确定”的单独场景：返回 503、将 API 标为未就绪，保留文件；恢复数据库连接后按材料 ID 核对，已提交则保留完整材料，未提交则清理，核对完成前不恢复业务。用故障注入分别验证“提交前断开”和“提交成功后应答丢失”。

材料服务当前包含未接入路由的开发草稿，不构成任务 6.4 的完成证据。待用户确认合同后实现完整恢复及集成测试。
